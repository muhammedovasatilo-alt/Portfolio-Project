# Asadillo Portfoliosi

Bu mening shaxsiy portfolio veb-saytim. Unda o'zim va bilgan texnologiyalarim haqida ma'lumot bor.

## Sahifalar

- **Asosiy**: men haqimda qisqacha ma'lumot, texnologiyalar va counter.
- **Men haqimda**: qiziqishlarim va bilimlarim.
- **Kontakt**: men bilan bog'lanish.

## Ishlatilgan texnologiyalar

- HTML
- CSS
- JavaScript

## Mini funksiyalar

- **Counter**: `+` va `-` tugmalari raqamni 0 dan 12 gacha o'zgartiradi. `Qaytarish` raqamni 12 ga qaytaradi.

## Qanday ishga tushiriladi

1. Papkani VS Code'da oching.
2. `Project.html` ustida o'ng tugma bosib, **Open with Live Server** ni tanlang.

## Muallif
